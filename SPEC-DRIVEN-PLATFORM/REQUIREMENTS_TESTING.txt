# Requirements for Spec-Driven Development Platform

## Core Dependencies

### Python Version
- Python 3.9+

### Testing Framework
```
pytest>=7.0.0
pytest-cov>=4.0.0
```

### Existing Platform Dependencies
(These are already in use by customer_health_platform.py)
```
anthropic>=0.7.0  # For Claude AI integration
```

### Type Checking (Optional)
```
mypy>=1.0.0
```

## Installation

### Install test dependencies
```bash
pip install pytest pytest-cov
```

### Install optional dependencies for enhanced development
```bash
pip install mypy black flake8
```

## Running Tests

### Basic test run
```bash
pytest tests/test_specifications.py -v
```

### With coverage report
```bash
pytest tests/test_specifications.py --cov=customer_health_platform --cov=specs
```

### Generate HTML coverage report
```bash
pytest tests/test_specifications.py --cov=customer_health_platform --cov-report=html
```

### Run specific test class
```bash
pytest tests/test_specifications.py::TestContactSpecification -v
```

### Run with verbose output
```bash
pytest tests/test_specifications.py -vv --tb=short
```

## Troubleshooting

### ImportError when running tests
Ensure the specs and tests directories are in Python path:
```bash
export PYTHONPATH="${PYTHONPATH}:$(pwd)"
```

### pytest not found
Install pytest:
```bash
pip install pytest
```

### Module not found errors
Make sure you're in the correct directory:
